⚠️ Scientific & Clinical Notice on Explainability

Grad-CAM computes spatial gradients from the final convolutional feature maps to illustrate which regions in the scan influenced the network's score. Grad-CAM is a model explanation visualization tool to aid radiologist review; it is NOT independent proof of clinical diagnosis.

Mathematical Formulation

Selvaraju et al.

The importance weight αkc for each feature map Ak with respect to class score yc is computed via global average pooling of the partial gradients:

αkc = (1/Z) ∑i ∑j (∂yc / ∂Ai,jk)

LGrad-CAMc = ReLU( ∑k αkc Ak )

The Rectified Linear Unit (ReLU) ensures that only positive influences contributing to class prediction c are projected into the visualization, discarding negative attributions.
